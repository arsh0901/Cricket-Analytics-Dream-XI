# 📊 Overview

- Analyzed **500+ records** from T20 World Cup 2022
- Cleaned and transformed raw cricket data
- Built an interactive dashboard for exploration
- Evaluated players using:
  - Strike Rate
  - Economy Rate
  - Wickets
  - Runs
  - Match Impact

- **Languages**

  - SQL

- **Libraries**
  - pandas
  - numpy

- **Data Wrangling**
  - Power Query

- **Visualization**
  - Power BI

  - Jupyter Notebook
  - Power BI Desktop

# 🎯 Objectives

- Extract, clean, and transform match data
- Compute player performance metrics
- Automate Top 11 player selection using KPIs
- Build an interactive Power BI dashboard

---

# 🔄 Process

- **Data Collection**
  - Gathered match and player statistics
  - Included runs, wickets, and performance data

- **Data Cleaning & Transformation**
  - Used pandas and Power Query
  - Handled null values
  - Standardized player names
  - Formatted date fields

- **Feature Engineering**
  - Created:
    - Strike Rate
    - Batting Average
    - Economy Rate
    - Impact Score
  - Applied filters:
    - Minimum matches
    - Minimum runs/overs

- **Dashboard Creation**
  - Built Power BI dashboard
  - Added charts, filters, and KPIs
  - Enabled player comparisons

---

# ✨ Key Features

- Automated **Top 11 player selection**
- Role-based analysis:
  - Batsman
  - Bowler
  - All-rounder
- Interactive dashboard
- Complete data pipeline
